# API 0.1.0

Canonical DTOs: `crates/hre-core/src/types.rs`. `docs/openapi.json` was generated by `just openapi` (exit marker 0); `/openapi.json` serves the schema generated from current source. After recent edits, a fresh check is pending. UUID event IDs and RFC3339 UTC timestamps are required.

`POST /v1/analyze` accepts JSON `AnalyzeRequest`. `X-API-Key` authenticates clients; moderator routes require `Authorization: Bearer <token>`. Errors use RFC 7807 `application/problem+json`. JSON requests are limited to 1 MiB and authenticated credentials to 600 requests/minute. CORS only permits explicitly configured origins.

| Method/path | Behavior |
|---|---|
| GET /v1/health | Public readiness and degradation |
| GET /v1/health/models | Model registry health, hash verification and degraded fallback; no inference readiness claim |
| GET /openapi.json | Generated schema |
| GET /docs | Offline contract link; Swagger assets not yet vendored |
| POST /v1/analyze | Message/call scoring; mock also accepts media metadata |
| POST /v1/events/refusal | Refused sender → refusing recipient; block/unblock/mute/stop_request |
| GET /v1/alerts | Moderator; persisted alert queue |
| GET /v1/stream/alerts | Moderator SSE; alert and resync events |
| GET /v1/subjects/{id}/feed-protection | HMAC subject ID; persisted protection state |
| POST /v1/admin/demo/reset | Moderator; disabled unless demo mode; reset currently 501 |

An exact non-draft retry returns its persisted response. Changing the envelope with the same event ID returns 409. Drafts run against history without writing events, cached results or alerts; a risky draft returns `nudge`.

All eight signal keys always exist. Status is `built`, `simulated`, or `roadmap`; unimplemented signals use backend `disabled`, confidence 0. This resolves the source prompt's inconsistent `disabled` status example in favor of its mandatory three-status enum. Mock outputs always set simulated=true and alert_id=null. Prefixes: `mock:polite_stalker`, `pile_on`, `cyberflasher`, `screenshot`, `voice_note`, `call_log`, `heavy_benign`, `slang`, `evidence` (each with `mock:`).

Real JSON media analysis returns 501 until multipart/modality integration lands. Real message scoring uses a minimal explicit-threat heuristic and behavior/fusion rules; call events use supplied metadata, not call-log import or audio analysis. Other unimplemented paths return a problem response. Mock slang and evidence responses demonstrate client rendering only; they do not mutate a lexicon or produce a hash chain.
